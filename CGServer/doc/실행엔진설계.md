# 실행엔진 설계 (cg-editor 결과물 → cg-streamer CEF 실행)

작성일: 2026-10-01 / 상태: 초안(전략 단계, 소스 미수정)

## 1. 목표

cg-editor(Next.js 저작도구)가 저장한 프로젝트 JSON을 cg-streamer(CEF, RK3588급 ARM 리눅스)에서 그대로 재생해 TS/UDP로 송출한다. 에디터 미리보기와 방송 출력이 같은 모양이어야 한다.

## 2. 현재 상태 (조사 결과)

| 항목 | 내용 |
|---|---|
| 저장 포맷 | `format:'cg-editor', version:2` JSON. `pages`, `items`, `channels`(stamps/global), `runSettings`, `styles`, `templates` |
| 렌더링 | DOM이 아닌 Konva(canvas). 글자는 `text-render.ts`의 `drawText`가 글자 단위로 직접 그림(자간/장평/3중 외곽선/그림자/run 스타일) |
| 애니메이션 | `effects.ts`의 `visual()`, `model.ts`의 `effectState()`는 시간→값 순수 함수. 재생 흐름은 `playbackStep`, `channelStep` |
| 미디어 참조 | `data:` URI 또는 `/api/media/<id>`(Cloudflare D1/R2). CEF에서 직접 접근 불가 |
| cg-streamer | `--run --project=project.json`, `cefQuery('load')`로 JSON 읽기. 영상은 네이티브 MPP 디코딩 + RGA 합성, HTML은 투명 배경으로 위에 그림 |
| 기존 player.html | `cef-mpp/web/player.html`은 GrapesJS 스키마(`page.html/css/effectIn`)용. cg-editor JSON과 호환되지 않음 |

## 3. 결정 사항

1. **HTML로 저장하지 않는다.** JSON이 원본(source of truth)이고, CEF에서 돌아가는 공용 런타임이 JSON을 읽어 렌더링한다.
   - 이유: 글자 단위 렌더링, 효과 13종, 시계/계수기, 채널 상태머신이 canvas+시간 함수로 만들어져 있어 HTML/CSS 변환 시 미리보기와 출력이 달라질 위험이 큼. 방송 중 값 변경과 round-trip 편집도 JSON이 유리.
2. **영상 아이템의 효과는 실행엔진에서 지원하지 않는다.** 에디터에 설정이 있어도 런타임은 무시한다.
   - 영상은 배치 rect(x, y, w, h), 시작/종료 시간, 반복, 트림, 볼륨만 네이티브로 전달.
   - 에디터에서 영상 아이템의 효과 UI를 비활성화하거나 "실행엔진 미지원" 표시를 넣는 것을 권장(미리보기/출력 불일치 방지).
3. **제어는 HTTP로 한다.** cg-streamer에 내장 HTTP 서버를 두고 REST 형태로 명령을 받는다. (UDP 제어는 전환기에만 병행하고 이후 제거. 영상 송출용 UDP/TS 출력과는 별개.)
   - 이유: 응답/상태 조회 가능, 패킷 크기 제한 없음(긴 한글 자막 OK), 웹UI·스위처·curl 등 연동이 쉬움.

## 4. 전체 구조

```
cg-editor (Next)              cg-streamer (CEF)
 JSON + media 내보내기 ─────►  project.json + media/
                               │ cefQuery('load')
                               ▼
                    cg-runtime (공용 JS 번들: model/effects/text-render/Konva)
                               │ canvas 1920x1080 (배경 transparent)
                               ▼
                    OnPaint → RGA 합성(+MPP 영상) → MPP 인코딩 → TS/UDP

 HTTP 127.0.0.1:<port> ─► 핸들러 ─► CefPostTask(UI) ─► ExecuteJavaScript("cg.xxx()")
                      └─► GET /status (런타임이 cefQuery로 올려준 상태 캐시)
```

영상 아이템만 예외로, 웹 렌더러가 그리지 않고 `video:play / video:rect / video:stop` 브릿지로 네이티브 MPP가 그린다(HTML 레이어가 그 위에 합성).

## 5. 구성 요소

### 5.1 공용 렌더 코어 (에디터·런타임 공유)
- `model.ts`(effectState, playbackStep, channelStep, normalizeProject, clockText), `effects.ts`(visual), `text-render.ts`(drawText)를 React/Next 비의존 패키지로 분리.
- `editor-canvas.tsx`의 "그리기" 부분을 공유 가능한 형태로 정리.
- 목표: 에디터와 런타임이 같은 코드를 사용.

### 5.2 cg-runtime (player)
- `player.html` + 단일 번들 JS(esbuild/vite). Konva 포함, CDN 사용 금지(오프라인 방송 장비 가정).
- 동작: `load` → `normalizeProject` → `playbackStep`으로 페이지 진행 → Konva 렌더 → 로딩 완료 시 `ready` 신호(폰트/이미지 decode 후 2프레임 대기, 기존 방식 유지).
- 창이 1920x1080보다 작을 때(`--view`) 축소하는 `fit()` 유지.
- `window.cg` API로 제어 명령 수신.

### 5.3 미디어 처리
- `/api/media/<id>` 참조는 내보내기 시점에 풀어서 번들(폴더 또는 zip: `project.json` + `media/`)로 저장하고 `src`를 상대경로로 치환.
- 이미지/오디오: 웹 렌더러 처리.
- 영상: 네이티브 MPP. 상대경로는 프로젝트 파일 위치 기준(기존 동작).
- Global Animation(배경 영상): 전체 화면 rect로 `video:play`.

### 5.4 폰트
- 에디터에서 쓴 폰트를 번들에 포함하고 `@font-face`로 로드(ARM 리눅스에 폰트가 없을 수 있음).

## 6. HTTP 제어 명세

### 6.1 현재 구현 (전환 전, 참고)
[cg-streamer/main.cpp](../src/cg-streamer/main.cpp) UDP 수신 루프: `127.0.0.1:5555`, 버퍼 256바이트, `next`/`prev`/`goto N`/`quit`, UI 스레드로 `CefPostTask` 후 `Client::Exec`로 `cg.xxx()` 실행. 이 구조(수신 → UI 스레드 → JS 실행)를 그대로 재사용한다.

### 6.2 서버
- cg-streamer 프로세스 안에 경량 HTTP 서버 내장(후보: cpp-httplib 단일 헤더, 스레드풀). 별도 프로세스/Node 불필요.
- 옵션: `--http=<port>`(기본 예: 5555 재사용 또는 8080), `--bind=<addr>`(기본 `127.0.0.1`), `--token=<문자열>`(선택).
- 핸들러는 CEF UI 스레드에서 직접 실행하지 않고 `CefPostTask(TID_UI, ...)`로 넘긴다(기존 방식).

### 6.3 엔드포인트 (초안)

| 메서드 | 경로 | 동작 |
|---|---|---|
| POST | `/play`, `/stop`, `/clear`, `/cut`, `/skip`, `/next`, `/prev` | 페이지 진행 |
| POST | `/goto/{n}` | n 페이지(1부터)로 이동 |
| POST | `/stamp/{1\|2}/play`, `/stamp/{1\|2}/stop` | Stamp 채널 제어 |
| POST | `/global/play`, `/global/pause`, `/global/rewind` | Global Animation |
| PUT | `/text/{linkName}` | 본문(JSON `{"text":"..."}`, UTF-8)으로 텍스트 갱신 |
| GET | `/status` | 상태 조회 (JSON) |
| POST | `/quit` | 종료 |

응답: `200 {"ok":true}` / 오류 `4xx {"ok":false,"error":"..."}`.

`/status` 예: `{"ready":true,"page":3,"pages":10,"playing":true,"cycle":1,"stamps":[{"visible":true,"playing":false},null],"global":{"playing":true,"time":12.3}}`
- 상태는 런타임(JS)이 변화 시 `cefQuery('state:<json>')`로 네이티브에 올리고, 네이티브가 캐시해서 응답(핸들러가 JS를 동기 호출하지 않음).

### 6.4 안전/운영
- JS 실행문은 경로·인자를 검증해서 조립한다: `goto`는 정수 파싱, `linkName`은 화이트리스트(`^[\w-]{1,100}$`), 텍스트는 JSON 문자열로 넘겨 JS 인젝션 방지(문자열 직접 이어붙이기 금지).
- 기본은 loopback 바인딩. 외부 장비 제어가 필요하면 `--bind=0.0.0.0` + `--token`(헤더 `Authorization: Bearer ...`) 사용, 망 분리 전제.
- 요청 본문 크기 상한(예: 64KB)과 CORS 기본 비허용.
- 재생 명령은 멱등하게 설계(`/play` 중복 호출 시 오류 대신 현재 상태 유지).

### 6.5 에디터 연동
- cg-editor의 Playback UI가 같은 API를 호출하면 에디터에서 실제 출력 장비를 원격 제어할 수 있다(브라우저→스트리머 직접 호출 시 CORS/토큰 정책 필요).

## 7. 위험 및 확인 필요

| 폰트 | 대상 머신 폰트 부재 → 번들 폰트 포함 |

| 동일성 검증 | 같은 JSON·같은 시각에서 에디터/런타임 렌더 스냅샷 비교 테스트 |
| 영상 효과 불일치 | 결정 3-2에 따른 에디터 UI 표시 처리 |

## 8. 진행 순서

1. 공용 렌더 코어 분리안 확정(파일 경계, 패키지 구조)
2. cg-runtime 최소 버전: Still + text/rect/image + fade를 CEF에서 렌더
3. 효과 13종(영상 제외)과 Run Setting 재생
4. 영상 배치만 네이티브 연동 + Global Animation
5. HTTP 서버 내장(+ /status) → Stamp 채널·Global·텍스트 갱신 API, UDP 제거
6. 내보내기 번들(미디어 풀기)과 폰트 패키징

## 9. 미결 사항

- HTTP 포트 기본값, 토큰 사용 여부, HTTP 서버 라이브러리 선정(cpp-httplib 등)
- UDP 제어 병행 기간과 제거 시점
- 1단계 파일 분리안 상세
- 기존 GrapesJS player.html 처리 방침
- `/status`에 포함할 상태 항목 확정

## 10. 구현 현황 (2026-10-01)

### 폴더 규약 (2026-10-01 변경: media / project 분리)
```
bin/
├─ cg-streamer                 ← 실행 파일 (CEF 런타임 파일도 여기)
├─ web/                        ← player.html, cg-runtime.js (공용 실행엔진)
├─ project/                    ← 프로젝트 JSON (cg-editor 가 저장)
└─ media/                      ← 이미지·동영상·음성 원본 (에디터는 여기 파일만 가져옴)
```
- project JSON 안의 미디어 src 는 project 폴더 기준 상대경로 `../media/<파일>`.
- 실행: `cg-streamer --run --project=project/<이름>.json [--autoplay] [--http=5555 --bind=127.0.0.1 --token=...]`
- 에디터는 `scripts/files-server.mjs`(포트 8081)를 통해 bin/media 목록·스트리밍, bin/project 저장/열기를 한다(Worker 런타임은 디스크 접근 불가).

### 구현됨
- `bin/web/cg-runtime.js`: model/effects/text-render 를 Canvas2D 로 포팅(효과 13종, 글자 단위 렌더, 시계/계수기, Run Setting, Stamp 2채널). 헤드리스 Chrome 에서 렌더/명령 동작 확인.
- `src/cg-streamer/main.cpp`: HTTP 제어 서버(`--http/--bind/--token`), `cefQuery` 의 `base`(프로젝트 폴더 URL)·`state:`(상태 보고), `--autoplay`. UDP 는 병행 유지.
- `bin/cgctl.sh`: HTTP(curl) 기반으로 변경.
- `CMakeLists.txt`: 소스 경로를 `src/cg-streamer/` 로 수정(타깃 `cg_streamer`, 실행 파일 이름 `cg-streamer`).

### 제약 (의도된 것 포함)
- 영상은 네이티브(MPP)가 그리며 위치·크기만 반영: 효과/투명도/회전/트림/볼륨 무시, 동시에 1개, Global 영상은 play/stop 만(pause/rewind/mark 구간 미지원).
- 오디오 아이템은 재생하지 않음(TS 출력에 오디오 경로 없음).
- `data:` / `/api/media/<id>` 미디어는 실행 불가. bin/project 에 저장하면 파일 서버가 `data:` 를 bin/media 로 풀고 `../media/` 로 바꿈(구 프로젝트는 다시 저장 필요).
- 폰트는 대상 머신에 설치돼 있어야 함(번들 `@font-face` 미구현).
- 페이지 Out 효과 없이 clear/stop 은 즉시 사라짐.
- C++ 변경은 이 PC(Windows)에서 빌드하지 못해 컴파일 미검증 → 보드에서 빌드 확인 필요.
